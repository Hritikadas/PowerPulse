# HPX Raw Data

## How to download
1. Go to https://www.hpxindia.com → Market Results → DAM
2. Download trade reports for available dates (Jul 2022 onwards)
3. Place files here with naming convention: `hpx_dam_YYYY_MM.csv`

## Note
HPX data is used for cross-exchange comparison only.
The main ML pipeline runs on IEX data.
