# IEX Raw Data

## How to download
1. Go to https://www.iexindia.com → Market Data → DAM / RTM
2. Select date range and download CSV/Excel reports
3. Place files here with naming convention: `iex_dam_YYYY_MM.csv`

## Expected files
- `iex_dam_YYYY_MM.csv` — Day-Ahead Market hourly MCP & MCV
- `iex_rtm_YYYY_MM.csv` — Real-Time Market 15-min block data (optional)
